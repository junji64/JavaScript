JavaScript 변수는 데이터 값을 저장하기 위한 「그릇/용기(containers)」이다.

자바스크립트 변수는 다음 네 가지 방법으로 선언 할 수 있습니다.

  • 최신 자바스크립트
    • let 사용
    • const 사용
  • 이전 JavaScript
    • var 사용 (권장하지 않음)
    • 자동으로 (권장하지 않음)

다음의 예에서 x, y, 와 z 는 변수들이다:

let Example

let x = 5;
let y = 6;
let z = x + y;

const Example

const x = 5;
const y = 6;
const z = x + y;

대수학(algebra)에서와 마찬가지로, 프로그래밍에서 우리는 값을 담는데 변수(price1 같은)를 사용한다.

대수학(algebra)에서와 마찬가지로, 프로그래밍에서 우리는 수식(total = price1 + price1)에서 변수를 사용한다.

위의 예에서, total 이 11로 계산된다.

JavaScript 식별자(Identifiers)

모든 JavaScript 변수(variable)는 고유한 이름으로 식별되어야 한다.

이러한 고유한 이름들을 식별자(identifiers)라고 한다.

식별자는 짧은 이름이거나(x 나 y 같이),  좀 더 설명적인 이름(age, sum, totalVolume 같이)일 수 있다. 

변수(고유한 식별자)의 이름 작성을 위한 일반적 규칙들은 다음과 같다:

  • 이름에는 문자, 숫자, 밑줄 과 달러 기호가 올 수 있다.
  • 이름은 문자, 밑줄,(_) 또는 달러 기호 ($)로도 시작할 수 있다.
  • 이름은 대소문자를 구분한다. (X는 x와 다릅니다)
  • 예약어(JavaScript kewords) 들은 이름으로 사용될 수 없다.
   JavaScript 식별자들은 대소문자구분(case-sensitive)한다.

자바스크립트 밑줄(_)

자바스크립트는 밑줄을 문자로 취급합니다.

밑줄(_)이 포함된 식별자는 유효한 변수 이름입니다.

Example

let _lastName = "Johnson";
let _x = 2;
let _100 = 5;
Try it Yourself »

전문 프로그래머들 사이에서는 "비공개" 변수의 이름은 밑줄(_)로 시작하는 것이 관례입니다.

자바스크립트 달러 기호($)

자바스크립트는 달러 기호($)도 문자로 취급합니다.

'$' 기호가 포함된 식별자는 유효한 변수 이름입니다.

Example

let $ = "Hello world";
let $$$ = 2;
let $myMoney = 5;
Try it Yourself »

자바스크립트에서 '$' 기호를 사용하는 것은 흔하지 않지만, 전문 프로그래머들은 자바스크립트 라이브러리의 메인 함수에 대한 별칭으로 종종 사용합니다.

자바스크립트 변수 선언하기

자바스크립트에서 변수를 생성하는 것을 변수 선언 이라고 합니다.

자바스크립트 변수는 `let var` 또는 `const variable` 키워드를 사용하여 선언합니다.

let을 사용하여 변수 선언하기

let carName;

변수 선언 후, 해당 변수는 아무런 값도 갖지 않습니다(엄밀히 말하면 입니다 undefined).

변수에 값을 할당 하려면 등호(=)를 사용합니다.

carName = "Volvo";

대부분의 경우 변수를 선언할 때 값을 할당합니다.

아래의 예에서, carName이라는 변수를 만들고 "Volvo"라는 값을 할당합니다. :

Example

let carName = "Volvo";
Try it Yourself »

const를 사용하여 변수 선언하기

값이 변경되어서는 안 되는 경우에는 항상 const 를 사용하십시오.

const carName = "Volvo";

A Mixed Example

const price1 = 5;
const price2 = 6;
let total = price1 + price2 ;
Try it Yourself »

price1 과 price2라는 두 변수는 const 키워드를 사용하여 선언됩니다

price1과 price2의 값은 변경할 수 없습니다.

변수 total은 let 키워드를 사용하여 선언됩니다

total의 값은 변경될 수 있습니다.

JavaScript 데이터 형식

JavaScript 변수는 100 같은 숫자와 "John Doe" 같은 텍스트 값(person="John Doe")을 담을 수 있다.

프로그래밍에서  "John Doe" 와 같은 텍스트는 문자열(string)이라고 부른다.

JavaScript  는 데의터의 많은 유형을 다룰 수 있으나, 지금은 단지 숫자(numbers) 와 문자열(strings) 만을 생각합니다.

문자열(string)은 , 큰 따옴표나 작은 따옴표 안에 넣습니다.  숫자(number)는 따옴표 없이 씁니다.

숫자 값을 따옴표로 묶을 경우, 텍스트 문자열(string)로 간주됩니다.

Example

const pi = 3.14;
let person = "John Doe";
let answer = 'Yes I am!';

JavaScript 변수 선언(생성)

JavaScript 에서 변수를 만드는 것을, 보통 변수 "선언(declaring)" 이라고 부른다.

JavaScript 의 변수는 var 키워드를 사용해서 선언한다. 

let carName;

선언 후, 변수는 (값이 없어) 비어 있습니다.

변수에 값을 지정하려면 등호를 사용합니다:

carName = "Volvo";

그러나, 선언할 때  변수에 값을 할당 할 수도 있습니다:

let carName = "Volvo";

아래의 예에서, 우리는 carname 이라는 변수를 선언하 후, 여기에 값 "Volvo"를 할당하고, id="demo" 인 HTML paragraph 의 값에 넣어 준다. :

Example

<p id="demo"></p>

<script>
let carName = "Volvo";
document.getElementById("demo").innerHTML = carName;
</script>
Try it Yourself »
It's a good programming practice to declare all the variables at the beginning of a script.

블록 범위

ES6(2015) 이전에는 JavaScript에 블록 스코프가 없었습니다 .

자바스크립트는 전역범위 와 함수범위를 가지고 있었습니다 .

ES6에서는 두 가지 새로운 JavaScript 키워드인 let와 const 가 도입되었습니다 .

이 두 키워드는 자바스크립트에서 블록 스코프를 제공합니다.

Example

중괄호({}) 안에 선언된 변수는 해당 블록 외부에서 접근할 수 없습니다.

{
let x = 2;
}
// x can NOT be used here

함수 범위

함수 내부에서는 var, let, const으로 선언된 모든 변수는 함수범위(Function Scope)를 가집니다 .

Example

중괄호({}) 안에 선언된 변수는 해당 블록 외부에서 접근할 수 없습니다.

function myfunction() {
var x = 1;
let y = 2;
const z = 3;
}
// x can NOT be used here
// y can NOT be used here
// z can NOT be used here

전역 범위

var로 선언된 모든 변수는 항상 전역범위(Function Scope)를 가집니다 .

var로 선언된 모든 변수는 블록범위(Function Scope)를 가질수 없다 .

Example

중괄호({}) 안에 선언된 var 변수는 블록 외부에서 접근할 수 있습니다.

{
var x = 2;
}
// x can be used here

재선언 할 수 없음

let으로 선언된 변수는 재선언 할 수 없다. .

let 사용하여 선언된 변수를 실수로 다시 선언할 수는 없습니다

With let you can not do this:

let x = "John Doe";
let x = 0;

var으로 선언된 변수는 재선언 할 수 있다. .

With var you can do this:

var x = "John Doe";
var x = 0;

JavaScript 변수의 재선언

var 키워드를 사용하여 변수를 다시 선언하면 문제가 발생할 수 있습니다.

블록 내부에서 변수를 다시 선언하면 블록 외부에서도 해당 변수가 다시 선언됩니다.

Example

var x = 10;
// Here x is 10
{
var x = 2;
// Here x is 2
}
// Here x is 2
Try it Yourself »

let 키워드를 사용한 재선언은 이 문제를 해결할 수 있다.

블록 내부에서 변수를 다시 선언해도 블록 외부에서는 변수가 다시 선언되지 않습니다.

Example

let x = 10;
// Here x is 10
{
let x = 2;
// Here x is 2
}
// Here x is 10
